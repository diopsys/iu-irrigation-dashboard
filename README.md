# IU Irrigation Dashboard

A Home Assistant integration with its own sidebar panel for
[Irrigation Unlimited](https://github.com/rgc99/irrigation_unlimited) (IU).
You set up pumps, zones, sequences and schedules in the panel. The
integration writes the IU configuration for you, adjusts run times to the
weather with a daily water balance (FAO-56 evapotranspiration), and shows
what is running right now.

## Features

- **Overview:** a diagram per controller with pump, valves and sprinklers.
  The pump is green when it is on, and turns with water flowing only while
  it really draws power. Shows the remaining time of the current zone, the
  next and the last run.
- **Automatic:** per controller automatic on/off; per sequence switch zones
  on/off, set the duration per zone and see the planned time after the
  weather adjustment; per schedule months, weekdays, start time (fixed time,
  or before/after sunrise or sunset) and run time 0–200 %.
- **Manual:** pick zones and one run time for all (5–200 % of the default),
  or start a whole sequence. Stop at any time.
- **Weather:** evapotranspiration and rain per day, hourly rain forecast,
  soil water balance and factor per zone.
- **Statistics:** run time per zone, irrigation and rain per day or month,
  number of runs, pump energy; with a water meter or prices also water per
  day or month, water per zone and costs (water, base price, electricity).
- **Settings** (administrators): any number of controllers, each with its
  own pump (switch, optional power and energy sensor, electricity price,
  lead time, run-on) or connected directly to the water mains (optional
  water meter, base price per month, price per m³, wastewater under
  *Advanced*),
  zones with one or more valves, sequences (a zone may appear in several
  sequences with its own duration), schedules per sequence, weather sources
  and water balance parameters.
- **Tap mode:** a zone can be marked as a tap. In tap mode its valve opens
  whenever the pump runs and the zone is left out of the automatic run;
  switch it to irrigation mode (e.g. while on holiday) and it runs in its
  sequences again. Optionally the pump stays on from sunrise to sunset.
- **Languages:** German and English, following the Home Assistant language.

## How it works

- The integration owns the file `packages/iu_irrigation_dashboard.yaml`. It
  rewrites it after every change in the panel, validates it against the IU
  schema and calls `irrigation_unlimited.reload` – never during a run.
  Do not edit this file by hand.
- IU only switches the pump **on**. The integration switches it off 30 s
  after the last zone (or at sunset in day mode), so the pump does not
  cycle between zones.
- **Water connection without pump:** the controller is written to IU
  without a pump switch; tap mode and day mode are not available. With a
  water meter the consumption per zone is counted: the amount between two
  meter readings is shared among the zones that ran in that time. With the
  main meter of the house only that counts; with a separate garden meter
  (*meter measures irrigation only*) the statistics use the whole
  consumption of the meter. An imported IU configuration without pump
  becomes a water connection.
- **Water balance per zone:** every day the evapotranspiration (ET₀, FAO-56
  Penman-Monteith) of the previous day is taken from the long-term
  statistics of your weather sensors; effective rain is added (zones marked
  as covered get no rain). The soil storage is limited (default 10 mm).
  Every run credits its amount of water (minutes ÷ default × reference
  demand, or application rate × time if you measured it).
- **Run time:** factor = (deficit + ET₀ forecast for 24 h − effective rain
  today and in the forecast) ÷ reference demand (default 3 mm), at most
  200 %, multiplied by the schedule %, the base factor and the zone factor,
  in steps of 5 %. A zone at 0 % is skipped. While it rains (rain rate > 0
  or rain sensor on) zones with rain are skipped. The run times are applied
  to IU with `adjust_time` every 30 minutes, not during a run.
- On the first start an existing IU configuration (in `configuration.yaml`
  or a package) is imported: controllers, zones, sequences with durations
  and schedules. Afterwards remove your own IU configuration – the panel
  shows a warning as long as both exist, and IU is not reloaded. A section
  `irrigation_unlimited:` directly in `configuration.yaml` is already pointed
  out during setup; once you have checked the import, Settings → Repairs
  comments it out for you. It shows the affected lines first, saves a copy
  as `configuration.yaml.iu_backup_<date>` and changes nothing else in the
  file (no YAML rewrite, comments and `!include` stay). An IU configuration
  in a package has to be removed by hand.

## Requirements

- Home Assistant 2025.1 or newer.
- [Irrigation Unlimited](https://github.com/rgc99/irrigation_unlimited)
  (tested with 2025.12.0), installed via HACS.
- Packages enabled in `configuration.yaml`:

  ```yaml
  homeassistant:
    packages: !include_dir_named packages
  ```

- For the weather adjustment (optional, can be switched off):
  - rain counter in mm (total, with long-term statistics),
  - temperature, humidity and wind speed sensors with long-term statistics
    (`state_class: measurement`); temperature is required for the daily ET₀,
  - optionally a solar radiation sensor (W/m²). Without it, radiation is
    estimated from the daily temperature range (FAO-56 eq. 50, Hargreaves)
    with the coefficient kRs (0.16 inland, 0.19 near the coast; adjustable
    in the settings). With a radiation sensor this is only used for days
    without radiation data,
  - a `weather` entity with an hourly forecast (precipitation, probability,
    cloud coverage) for the 24 h forecast,
  - optionally a rain rate sensor (mm/h) or a binary rain sensor.

## Installation

1. HACS → three dots → *Custom repositories* → add
   `https://github.com/diopsys/iu-irrigation-dashboard` as type
   *Integration*, then install **IU Irrigation Dashboard**.
   (Manual: copy `custom_components/iu_irrigation_dashboard` to
   `/config/custom_components/`.)
2. Restart Home Assistant.
3. Settings → Devices & services → *Add integration* →
   **IU Irrigation Dashboard** (no options).
4. Open **Irrigation** in the sidebar → *Settings*: add a controller with
   pump and zones, a sequence and schedules, choose the weather sources and
   save. If IU was not loaded before, restart Home Assistant once more.

## Entities

| Entity | Description |
|---|---|
| `sensor.irrigation_run_time_<zone>` | minutes per zone (total, for statistics) |
| `sensor.irrigation_water_<zone>` | litres per zone at a water connection with meter (total, for statistics) |
| `sensor.irrigation_evapotranspiration` | ET₀ of yesterday (mm), attributes with forecast, rain and factor per zone |
| `sensor.irrigation_automatic_runs`, `sensor.irrigation_manual_runs` | number of runs |
| `sensor.irrigation_zones` | number of zones, attribute with all zones |

The names are German if Home Assistant is set to German when the entities
are created. The IU entities (`binary_sensor.irrigation_unlimited_c1_m`, …)
come from Irrigation Unlimited itself.

## Development

The panel is a single web component (`www/irrigation-app.js`, loaded by
`www/irrigation-panel.js` with a cache-busting timestamp – changes to the
app need no restart). Texts are written in German and passed through
`t()`; English translations live in `TEXTE.en`, keyed by the German text.
Tests: see [tests/README.md](tests/README.md).

## Deutsch

Eine Home-Assistant-Integration mit eigenem Panel für
[Irrigation Unlimited](https://github.com/rgc99/irrigation_unlimited) (IU).
Pumpen, Zonen, Sequenzen und Pläne werden im Panel eingerichtet; die
Integration erzeugt daraus die IU-Konfiguration, passt die Laufzeiten über
eine tägliche Wasserbilanz (Verdunstung nach FAO-56) an das Wetter an und
zeigt, was gerade läuft.

- **Reiter:** Übersicht (Anlagenbild je Controller, Pumpe grün = an,
  drehend nur bei Leistungsaufnahme), Automatik (Zonen je Sequenz an/aus,
  Dauer, geplante Zeit; Pläne mit Monaten, Tagen, Start fest oder vor/nach
  Sonnenauf-/-untergang, Laufzeit 0–200 %), Manuell (Zonen oder Sequenz mit
  einer Laufzeit 5–200 %), Wetter, Statistik, Einstellungen (nur Admins).
- **Pumpe oder Wasseranschluss:** Je Controller eine Pumpe (mit Strompreis
  für die Statistik) oder direkt die Wasserleitung ohne Pumpe. Am
  Wasseranschluss optional ein Wasserzähler – Hauptzähler (es zählt nur der
  Verbrauch während der Läufe) oder eigener Gartenzähler – sowie Grundpreis
  je Monat, Preis je m³ und unter „Erweitert“ Abwasser je m³. Die Statistik
  zeigt dann Wasser je Tag/Monat und Zone sowie die Kosten.
- **Wasserhahn-Betrieb:** Eine Zone kann ein Wasserhahn sein – das Ventil
  ist offen, solange die Pumpe läuft, und die Zone fehlt in der Automatik.
  Auf „Beregnung“ umgestellt (z. B. im Urlaub) läuft sie wieder mit.
- **Die Datei `packages/iu_irrigation_dashboard.yaml`** gehört der
  Integration und wird bei jeder Änderung neu geschrieben – nicht von Hand
  bearbeiten. Eine vorhandene IU-Konfiguration wird beim ersten Start
  übernommen und muss danach entfernt werden.
- **Voraussetzungen:** Home Assistant ab 2025.1, Irrigation Unlimited (HACS),
  `homeassistant: packages: !include_dir_named packages` in der
  `configuration.yaml`; für die Wetteranpassung Regenzähler, Temperatur,
  Luftfeuchte und Wind mit Langzeitstatistik sowie eine `weather`-Entität
  mit stündlicher Prognose. Ein Einstrahlungssensor ist optional – ohne ihn
  wird die Einstrahlung aus der Temperaturspanne geschätzt (FAO-56, kRs
  einstellbar).
- **Installation:** HACS → *Benutzerdefinierte Repositories* →
  `https://github.com/diopsys/iu-irrigation-dashboard` (Integration),
  installieren, neu starten, unter Geräte & Dienste „IU Irrigation
  Dashboard“ hinzufügen und im Panel „Beregnung“ unter *Einstellungen*
  einrichten.
- Die Oberfläche folgt der Sprache von Home Assistant (Deutsch/Englisch).
